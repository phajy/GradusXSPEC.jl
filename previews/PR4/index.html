GradusXSPEC.jl

GradusXSPEC connects Gradus.jl relativistic line profiles to XSPEC local models. Each model convolves an xillver reflection table with a corona geometry and accretion-disc setup. Parallel kerrz_* models obtain L(g) from the kerrz CLI for side-by-side comparison.

Load the package once in XSPEC with lmod gradusxspec ., then select any model name in model.

Quick start

  1. Build the Julia library and XSPEC package.
  2. Load and fit the models in XSPEC.
  3. Check parameter meanings and limits.
  4. Browse the example gallery for parameter scans and backend cross-checks.
  5. Validate spectra and generate plots before or alongside XSPEC testing.
